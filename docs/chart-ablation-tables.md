# Chart ablation: the cVAE decoder in place of the IKFlow chart

Generated by `python scripts/report_chart_ablation.py --write`; numbers only. Rows are the record's experiments (robot x task x start), 480 cells each, 180 s, seed 1, one solve per GPU. Columns: **flow** = the record's learned arm (IPOPT: stage PAPER, Panda stage SVGD_R2; AL-SVGD: SVGD_R29 `pin4`); **cVAE-K** = stage CVAE at K = the flow's width (Panda 7, iiwa 8, screw 7, soft PCS 12; the record's trust region); **cVAE-k** = K = the redundancy (Panda 1, iiwa 1, screw 1, soft PCS 6; trust region round(sqrt(K) + 1.5, 2)); **JS** = the record's joint-space arm (IPOPT: the same runs; AL-SVGD: SVGD_R30 `pin4kq`). Every cVAE run is refused unless its grid hash, scene fingerprint, cap and cells are the record row's. `not yet measured` = no merged 480-cell cVAE run collected yet.
