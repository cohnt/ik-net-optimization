# Chart campaign: LOInK in place of the IKFlow chart

Generated by `python scripts/report_loink.py --write`; numbers only. Rows are the record's experiments (robot x task x start), 480 cells each, 180 s, seed 1, one solve per GPU. **flow** = the record's learned arm (IPOPT: stage PAPER, Panda stage SVGD_R2; AL-SVGD: SVGD_R29 `pin4`; screw: SCREWREDO `n6r` where it exists); **JS** = the record's joint-space arm (IPOPT: the same runs; AL-SVGD: SVGD_R30 `pin4kq`). Charts are `loink<cost><act><recipe>`: cost m / x / u, activation r (relu) / t (tanh), recipe P (batch 4096, 620000 steps) / A (batch 500, 150000 steps); K = DOF - 6 (Panda 1, iiwa 1, screw 1, soft PCS 6), trust region round(sqrt(K) + 1.5, 2). Every chart run is refused unless its grid hash, scene fingerprint, cap and cells are the record row's and its checkpoint is the chart its tag names. `not yet measured` = no merged chart run collected. `x/60` = the 60-cell PROBE (guess 0 of every target), shown where the row has no full run; its pairings, costs and medians are over those 60 cells only. McNemar cells: `chart-only / other-only, p` on the discordant cells (exact two-sided). Cost cells: `median per-cell ratio chart / other [95% bootstrap CI over targets, 1000 resamples] (n shared cells)`, on cells both arms of the pair solved, `--` under 10; the reported cost, learned-only regularisers excluded. Cap check: `clock` / `budget` = cells stopped by the wall clock / an iteration budget (>= 24 at a budget is flagged **VOID**).
